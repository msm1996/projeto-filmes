# 🎬 Catálogo de Filmes

Aplicação Front-End desenvolvida com **React.js** que consome a **API do TMDB** para exibir filmes e séries em um catálogo interativo e responsivo.

A aplicação permite navegar pelo catálogo, visualizar informações dos filmes, consultar sinopses e assistir a trailers, utilizando dados obtidos dinamicamente através de uma API externa.

## 🚀 Sobre o projeto

O **Catálogo de Filmes** foi desenvolvido para praticar conceitos importantes do desenvolvimento Front-End com React.js e integração com APIs.

A aplicação consome dados da **API do TMDB** utilizando Axios e apresenta as informações de forma dinâmica na interface.

Os dados fornecidos pela API são utilizados para exibir informações como imagens, títulos, sinopses e trailers, proporcionando uma experiência semelhante à de plataformas de catálogo de filmes.

---

## ✨ Funcionalidades

- 🎬 Listagem de filmes e séries
- 🔍 Visualização de detalhes dos filmes
- 🎥 Exibição de trailers
- 🖼️ Banner com imagem e sinopse
- ⚡ Consumo dinâmico da API do TMDB
- ♻️ Componentes reutilizáveis
- 🔄 Navegação entre páginas
- 📱 Interface responsiva

---

## 🛠 Tecnologias utilizadas

- **React.js** — construção da interface e componentização
- **JavaScript** — lógica e manipulação dos dados
- **Axios** — requisições para a API
- **Styled Components** — estilização dos componentes
- **React Router DOM** — navegação entre páginas
- **TMDB API** — fornecimento dos dados de filmes e séries

## 🌐 API utilizada

O projeto utiliza a **TMDB API (The Movie Database)** para obter informações sobre filmes e séries.

Através da API, a aplicação recebe dados que são utilizados para montar dinamicamente o catálogo e apresentar informações dos conteúdos na interface.

## 💻 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/msm1996/projeto-filmes.git
```

Entre na pasta do projeto:

```bash
cd projeto-filmes
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
